# 书中人

上传一本书，认出作者与主要角色，蒸馏成可对话的 AI 分身——按原著语气与立场说话。

**产品地址：** [https://bookpersonae.dewyue.com](https://bookpersonae.dewyue.com)

## 能做什么

1. 注册登录，每人独立书架（数据隔离）
2. 上传 PDF / EPUB / TXT / MD
3. 自动生成作者 / 角色分身，并基于原文引用对话
4. 自带 AI 密钥（硅基流动等），额度归你自己

## 关于本仓库

这是**产品展示仓库**：界面与账号能力可见，**书籍解析 / 分身蒸馏 / RAG 等核心实现未开源**。

克隆后无法复刻完整流水线；请直接使用线上产品。

## 隐私

- 用户书架与对话按账号隔离
- AI 密钥保存在浏览器 Cookie，不进入本仓库
